EMBERFALL — a night-garden arena defence game that runs entirely in the browser. You are the keeper of the last lantern in a dark garden: moths, gnats, beetles and fireflies swarm in from the dark to snuff it out. Move with WASD or the arrow keys, aim with the mouse and hold click to throw embers. Survive all 10 waves, pick an upgrade between waves, chain kills into combos, and face the Moth Queen on the final night. Static files, no build step, fully offline — every sprite is drawn in code and every sound is synthesized with WebAudio.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
